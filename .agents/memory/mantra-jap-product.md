---
name: Mantra jap product direction
description: Product constraints for future changes to the Hindu Mantra Jap Counter.
---

Keep jap counts, selected mantra, goals, settings, and history stored locally on the device so practice remains available after restart.

**Why:** The user explicitly requested persistent local practice data and a calm, temple-inspired saffron, cream, and gold design.

**How to apply:** Use local persistence for future practice features unless the user asks for sync, and keep new screens consistent with the spiritual visual direction.
