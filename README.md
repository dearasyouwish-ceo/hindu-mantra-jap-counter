
# Hindu Mantra Jap Counter

A mobile-friendly Hindu mantra counting app with:

- Centered jap counter and tap-to-count button
- Visual 108-bead mala
- Built-in mantras and custom mantra support
- Daily repetition goals and streaks
- Daily, weekly, monthly, and yearly history
- Undo and session reset
- Multiple color themes
- Local browser storage

## Deploy on GitHub Pages

1. Add `index.html` to the root of this repository.
2. Commit the file to the `main` branch.
3. Open Settings → Pages.
4. Select Deploy from a branch.
5. Choose `main` and `/(root)`.
6. Click Save.

Live URL:

https://dearasyouwish-ceo.github.io/hindu-mantra-jap-counter/

Progress is stored locally in the browser and is not automatically synchronized across devices.
